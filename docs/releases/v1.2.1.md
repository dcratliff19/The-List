# The List 1.2.1

This patch release improves maintainability and reliability across the app and
sharing service while preserving existing projects, backups, and sharing formats.

## Changes

- Reorganized the app and server into focused, documented modules.
- Fixed database clock rollback and protected newer workspace schemas.
- Improved sync lifecycle handling and validation of incomplete encrypted frames.
- Enforced session revocation during uploads and relay credential refreshes.
- Added indexed project queries and expanded regression tests.

## Windows installation

Download `The-List-1.2.1+6-Windows-x64.zip` and its `.sha256` companion. Extract
the entire ZIP and run `the_list.exe` inside it. Keep every DLL and the `data/`
folder together. The package includes the illustrated guide, changelog,
architecture notes, and unpacked Chrome/Edge capture extension.

If the Visual C++ runtime is missing, install Microsoft's
[x64 Redistributable](https://learn.microsoft.com/en-us/cpp/windows/latest-supported-vc-redist).

Before upgrading, export a workspace backup and close the old app. Existing data
is stored outside the application folder; Settings shows its location. If the
executable moves, enable browser capture again and save daily backup settings
from the new location.

This folder-based package has no installer, automatic updater, or code signature.
Sharing requires a separately configured connection service. Server source is
included in the repository; the Windows ZIP does not deploy it.

## Validation

Validated locally on Windows: 47 app tests, clean Dart analysis/formatting, a
Windows release build, and real WebRTC/photo/reconnection/permission/offline
integration. All 20 server tests passed on Node 22 and 24, and the server image
passed container smoke checks. Linux reminder helper and Windows SQLite
preparation regressions passed. Other native platform builds and public-network
TURN acceptance were not rerun for this release.
